### 1. Controlled Inference Categories (Section 43)

An inferred relationship is never presented as an empirically verified direct fact. Every edge carries an explicit `InferenceType`:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   ZMIE INFERENCE CLASSIFICATION                        │
├──────────────────────────┬─────────────────────────────────────────────┤
│ Category                 │ Operational Definition                      │
├──────────────────────────┼─────────────────────────────────────────────┤
│ 1. DIRECT_FACT           │ Directly reported observation in an         │
│                          │ authoritative statutory or trial document.  │
├──────────────────────────┼─────────────────────────────────────────────┤
│ 2. SUPPORTED_RELATION    │ Relation grounded by one or more            │
│                          │ published, peer-reviewed empirical studies. │
├──────────────────────────┼─────────────────────────────────────────────┤
│ 3. DERIVED_RELATION      │ Logically deduced through strict subsumption│
│                          │ hierarchies (e.g. A is_a B, B treats C).    │
├──────────────────────────┼─────────────────────────────────────────────┤
│ 4. COMPUTATIONAL         │ Generated by in-silico QSAR, docking,       │
│    INFERENCE             │ or graph link prediction models.            │
├──────────────────────────┼─────────────────────────────────────────────┤
│ 5. RESEARCH_HYPOTHESIS   │ Speculative research path identified by     │
│                          │ autonomous Deep Research reasoning agents.  │
└──────────────────────────┴─────────────────────────────────────────────┘
```

### 2. Inference Provenance (Section 44)

Every derived or inferred edge must record complete reasoning provenance:
- **`inference_method`**: Symbolic deductive rule, multi-hop path traversal, or GNN link prediction.
- **`input_edges`**: List of direct relationship IDs used as premises.
- **`input_claims`**: Underlying atomic claims grounding the premises.
- **`algorithm_version`**: e.g. `path_finder_v2.1`.
- **`reasoning_run_id`**: Persistent UUID enabling audit of the exact computational execution.

### 3. Multi-Hop Reasoning Boundaries (Sections 42, 55, 56)

1. **Non-Transitivity of Causal Links**:
   - Transitive chains of association do not establish causal efficacy:
     $$A \xrightarrow{\text{ASSOCIATED\_WITH}} B \land B \xrightarrow{\text{ASSOCIATED\_WITH}} C \centernot\implies A \xrightarrow{\text{CAUSES}} C$$
2. **Confidence Decay**:
   - For multi-hop inferred paths, confidence decays exponentially with hop count ($k$):
     $$\text{Confidence}_{\text{path}} = \prod_{i=1}^k \text{Confidence}(e_i) \times \gamma^{k-1} \quad (\gamma = 0.85)$$
